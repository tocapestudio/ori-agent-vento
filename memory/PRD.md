# Ori — PRD

## Original problem statement
"Ori": Spanish AI assistant for clinical optometry, vision therapy and sports vision. FARM stack, /api prefix, /api/openapi.json.
Phase 0 POC: ingestion (PDF text / scanned PDF OCR, DOCX, XLSX, PPTX, PNG/JPG) → chunks with refs; scope common | profile:<id>; tags/notes; hybrid Spanish retrieval with scope filter; grounded Spanish answers with inline citations; explicit "no lo encuentro"; web search only when toggled (ddgs) with "Fuente web" labels; persona; multi-turn.
Decision change: NO paid AI. Runs locally on the user's Windows PC, team accesses it over the clinic LAN. LLM = Google Gemini with the user's own free-tier key (google-genai SDK); Ollama optional fallback.
Phase 1: team access code "Orion9944+" (hashed, changeable) → "¿Quién eres?" profile picker (CRUD, no passwords); Library (Común / Mi biblioteca, originals on disk with preview/download, tags/notes, search/filter, status); Chat (sidebar history per profile + view other profiles, per-message scope, web toggle, clickable citation chips, streaming, quick actions, anonymized banner); Ori robot expressions; persisted local vector index; Settings (provider, Gemini model/key, Ollama, access code).

## Architecture
- backend: server.py (startup: seed code, indexes, index sync, re-queue processing), auth.py (bcrypt + JWT, lockout), routes_core.py (auth, profiles, settings), routes_documents.py (upload/storage/preview/download/process), routes_chat.py (SSE chat, conversations), llm.py (GeminiProvider w/ retry+fallback, OllamaProvider), settings_store.py (env defaults + Mongo overrides), retrieval.py + vector_index.py (fastembed mpnet multilingual → numpy index on disk + Mongo $text spanish, RRF), ingest.py, websearch.py, prompts.py
- storage: STORAGE_DIR originals, INDEX_DIR vectors; Mongo: documents, chunks, profiles, conversations, messages, settings, login_attempts
- frontend: AccessGate, ProfilePicker, AppShell, ChatPage, LibraryPage, SettingsPage + components (chat/docs/layout/ori). Ori images in public/ori/*.jpg
